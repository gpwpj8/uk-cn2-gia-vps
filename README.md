## “三网回程 GIA”这句话，得拆开看

先把关键信息说清楚：**电信和联通的回程确实走 CN2，移动的回程走 CMIN2，不是 CN2 GIA。**

按目前可查到的线路说明，三条路径大致是这样：

- **电信**：去程走 CN2 骨干直连法兰克福，再进伦敦；回程走 CN2 直连回国，双程都是 CN2。
- **联通**：去程 AS4837 接 AS10099，从法兰克福落地后转到伦敦；回程被强制切到电信 CN2 链路回来。
- **移动**：去程 CMI 直连法兰克福；回程走 CMIN2 直连回国。

移动回程是 CMIN2 这件事，对移动宽带用户影响不大，CMIN2 本身就是移动的国际精品网，晚高峰表现通常比普通 CMI 好。但如果你的预期是“三条线全部 59.43”，那实际体验和宣传口径对不上，容易产生落差。

### 自己怎么验

下单前后都可以用测试 IP `185.217.110.10` 跑一遍：

1. 在本地机器上执行 `traceroute 185.217.110.10`（Windows 用 `tracert`），看**去程**经过哪些节点。
2. 在 VPS 上反向执行 `traceroute 219.141.147.210`（北京电信）、`210.22.97.1`（上海联通）、`211.136.112.200`（上海移动），看**回程**。
3. 回程路径里出现 `59.43.x.x` 段，这一段就是走了 CN2 GIA；只有 `202.97.x.x` 则是普通 163 骨干。
4. 移动回程如果看到 `223.x` 或 CMIN2 相关段，说明走的是移动精品网而非电信 CN2。

商家还提供了 Looking Glass（`lonlg.akkocloud.com`）和 1000MB 测速文件，可以先在本地 ping 一下延迟，再决定要不要买。

## 2022 年 5 月的伦敦实测数据，能说明什么

手头能查到的最完整一次第三方实测在 2022 年 5 月 29 日，测试机是 1 核 Intel Broadwell 2.1GHz、731MB 内存、9.4GB 磁盘、CentOS 7.9，对应 768MB 那一档。数据放在今天看只能当参考，但几个指标仍有意义。

**硬件性能**：硬盘 I/O 三次测试 470 / 726 / 741MB/s，平均 645.7MB/s；UnixBench 单核得分 649.3。这个分数对共享型 KVM 来说属于正常偏好，说明当时母机负载不高。

**国内延迟**：Speedtest 上海 176.48ms、南京 159.78ms、广州 171.17ms。另一份 2023 年的测评本地 ping 在 180ms 左右，国内节点平均约 192ms。伦敦到中国的物理距离摆在那，180–200ms 已经是优化线路才能做到的数字，普通欧洲线路通常 250ms 起。

**带宽**：Speedtest 上海上行 373.71Mbps / 下行 211.77Mbps，南京 388.73 / 249.39Mbps，广州 346.71 / 167.23Mbps。iperf3 对伦敦本地 386 / 253Mbps，对巴黎 385 / 236Mbps，对纽约 372 / 177Mbps。标称 500Mbps，实测跑到三四百兆，没有明显缩水。

**流媒体**：同一天的伦敦 IP 上，Netflix 识别为 GB、Disney+ 为 US、YouTube Premium 为 GB，BBC iPlayer、ITV Hub、Channel 4、Sky Go、BritBox 都能开，DAZN 不可用。IP 归属查出来是 Kirino LLC 的 38.59.*.* 段。

这些是四年前的单次测试，商家后来调整过线路，现在的实际表现可能更好也可能不同。别把它当成当前性能承诺，当成“这台机器曾经跑到过什么水平”更合适。

## 广播 IP、非原生、不退款：三条只写在条款里的限制

伦敦节点的 IP 是广播 IP，不是英国本地原生 IP。2022 年那次测试查到的归属是 Kirino LLC，注册地在美国。这不影响正常使用，但对 IP 归属地有要求的业务（比如需要英国本地身份验证的注册、某些区域性服务）会碰到问题。

更需要注意的是商家的服务条款：**不保证分配到的 IP 是原生 IP，并且明确不接受“不是原生 IP”作为退款理由。** 这条写在 Tos 里，商品页上看不到，很多人是买完发现 IP 归属不对才回头翻。

流媒体解锁同理。2022 年那次测试里 Netflix、BBC iPlayer、ITV Hub 这些都能开，但流媒体平台的风控一直在变，商家也没承诺长期解锁。指望它当稳定的解锁节点，风险要自己承担。

付款方式上，公开信息显示支持支付宝，没有看到 PayPal 或信用卡渠道的可靠说明。海外用户或者需要信用卡付款的，下单前先在结账页确认可选的支付方式。

## 几个常见问题

**299 元那档够用吗？**

看用途。跑一个静态博客、一两个轻量服务、偶尔连一下，512MB 内存够。要装 WordPress 加几个插件、跑 Docker、同时开数据库，512MB 会频繁触发 OOM，直接上 449 元的 768MB 档，多花的 150 元省下的是折腾时间。

CMIN2 是移动自己的国际精品线路，移动用户走这条回程，实际体验未必比 CN2 差，甚至可能更顺。真正需要留意的是电信和联通用户，你们的回程确实走 CN2，这部分和宣传一致。买之前用测试 IP 跑一遍回程 traceroute，比看任何测评都准。
